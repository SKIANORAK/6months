# 6 months 3D Studio

MCP-сервис для подготовки 3D-персонажей и одежды для виртуальной примерочной бренда **6 months**.

## MVP

- создание чернового персонажа по изображению;
- генерация персонажа в A-pose;
- экспорт результата в GLB;
- создание черновой 3D-модели одежды;
- проверка состояния асинхронных задач;
- автоматический риггинг humanoid-персонажей;
- закрытая модель: без гениталий, сосков и nude-режима.

На первом этапе сервис использует Meshy API. Позже можно добавить адаптеры Tripo или другого провайдера, не меняя инструменты плагина.

## Важно

Этот проект не обучает собственную нейросеть для 3D с нуля. Он управляет внешним генератором, защищает ключи, проверяет входные данные и формирует единый процесс подготовки моделей.

Автоматическая генерация одежды пока создаёт черновой GLB. Финальная посадка вещи на пять персонажей, единый скелет и проверка пересечений потребуют отдельного Blender-пайплайна.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Настройки:

```env
PORT=8787
MESHY_API_KEY=ключ_Meshy
PLUGIN_TOKEN=длинная_случайная_строка
ALLOWED_IMAGE_HOSTS=
```

`MESHY_API_KEY` и `PLUGIN_TOKEN` нельзя добавлять в GitHub.

## Адреса

```text
GET  /health
POST /mcp
```

Для `/mcp`:

```text
Authorization: Bearer <PLUGIN_TOKEN>
```

## Инструменты MCP

- `create_character_from_image`
- `create_clothing_from_image`
- `get_model_status`
- `rig_character`
- `get_rigging_status`
- `describe_pipeline`

## Безопасность персонажей

Финальные персонажи примерочной должны соответствовать постоянным правилам:

- в геометрии отсутствуют анатомические гениталии;
- отсутствуют соски и анатомически подробная грудь;
- на персонаже всегда есть неснимаемый непрозрачный базовый слой;
- интерфейс не содержит команды полного раздевания;
- части тела под одеждой можно скрывать масками, чтобы тело не проходило сквозь ткань.
