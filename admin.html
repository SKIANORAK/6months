вход владельца

обычный пароль здесь не используется. нужен личный github token с доступом только к репозиторию 6months и правом contents: read and write. token хранится только до закрытия вкладки.

как создать token
  1. github → settings → developer settings
  2. personal access tokens → fine-grained tokens
  3. выбрать репозиторий 6months
  4. repository permissions → contents → read and write
  5. создать token и вставить его ниже
